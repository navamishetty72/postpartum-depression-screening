# Research: Methodology & Experimental Governance

This directory contains verified methodological governance documents, clinical conditioning matrices, and partition verification reports.

## Core Documents
- **`CLINICAL_CONDITIONING_MATRIX.csv`:** Specification of permissible non-target clinical conditioning predictors, classification of biological plausibility, and documentation of survey missingness patterns.
- **`TRAIN_TEST_SPLIT_VERIFICATION.md`:** Verification report establishing the immutable 640-train / 160-test stratified partition (`random_state=42`) with zero participant overlap.
- **`PRIVACY_VALIDATION_BOUNDARIES.md`:** Formal boundary decoupling tabular Gower DCR/NNDR from synthetic audio, video, and text data realities.
