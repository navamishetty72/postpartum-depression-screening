# Test Suite

## Overview
Comprehensive test suite covering unit tests, schema contracts, integration tests, and leakage assertions.

## Test Categories
- `tests/clinical/`: Preprocessing, scoring, and numerical baseline unit tests.
- `tests/audio/`: Acoustic feature parsing and pipeline tests.
- `tests/text/`: NLP tokenizer, transcript, and sentiment tests.
- `tests/video/`: OpenFace tabular parsing and dropout tests.
- `tests/fusion/`: Late fusion combiner and modality alignment tests.
- `tests/backend/`: FastAPI endpoint integration and payload validation tests.
