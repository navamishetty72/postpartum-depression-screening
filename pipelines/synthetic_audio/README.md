# Synthetic Audio Feature Pipeline

## Scientific Framework & Modality Disclaimer
> [!IMPORTANT]
> **Architectural Benchmark Only:** The Bangladeshi clinical survey cohort contains **zero physical audio recordings**. The synthetic audio feature profiles generated by this pipeline are computationally conditioned fixtures derived from non-target clinical covariates. They exist solely to benchmark multimodal fusion architectures and stress-test tensor ingestion pipelines. They do **not** represent genuine acoustic observations and cannot validate real-world clinical diagnostic efficacy.

## Pipeline Architecture
- `config.py`: Physiological bounds, baseline priors, correlation structure, linear conditioning weights, and tensor dimensions.
- `conditioning.py`: Extracts and normalizes approved non-target clinical covariates (`norm_age`, `sleep_disruption`, `support_deficit`, `infant_distress`, `maternal_affect`), strictly fitted on the 640 training participants.
- `generator.py`: Generates correlated summary scalars via Multivariate Normal sampling with boundary clamping, and abstract $(T, 128)$ temporal embedding fixtures via an AR(1) process ($\alpha = 0.85$, $T \in [30, 90]$).

## Generated Outputs
Outputs are saved to `data/synthetic/audio/` (configured in `.gitignore`):
- `audio_manifest.csv`: 800 participant records (640 train, 160 test) linked to `BGD_001`–`BGD_800`, containing:
  - `participant_id`
  - `split_partition` (`train` / `test`)
  - 7 summary scalars: `f0_mean_hz`, `f0_std_hz`, `jitter_local_percent`, `shimmer_local_percent`, `hnr_db`, `speech_rate_syllables_per_sec`, `pause_ratio`
  - `sequence_length` ($T_i \in [30, 90]$)
  - `embedding_path` (`data/synthetic/audio/features/BGD_xxx.npy`)
  - `data_origin` (`CLINICALLY_CONDITIONED_SYNTHETIC`)
  - `generation_seed` (42)
- `features/`: 800 NumPy `.npy` files of shape $(T_i, 128)$ and dtype `float32`.

## Execution & Verification
To regenerate the synthetic cohort:
```bash
python -m pipelines.synthetic_audio.generator
```

To run the automated validation test suite:
```bash
pytest tests/test_synthetic_audio.py -v
```
All 12 automated checks verify participant ID alignment, physiological bounds, zero NaNs/Infs, train/test isolation, deterministic reproducibility, and provenance integrity.
